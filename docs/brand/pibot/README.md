# 피봇

앱 캐릭터. 상황에 따라 그림만 바꿔 끼운다. 한 화면에는 하나만 쓴다.

기본 모습은 페리윙클 몸, 검은 바이저, pb 모양 눈, 안테나 끝 유리구슬. 팔은 소품 들 때만 나온다.

## 상태

| 파일 | 상태 | 언제 | 어디에 |
|---|---|---|---|
| `pibot-base` | 기본 | 다른 상태가 아닐 때 | 채팅 프로필, 스플래시, 빈 화면 |
| `pibot-planning` | 일정 짜는 중 | `plan_trip` 응답 기다리는 동안 | 일정 짜는 중 화면, 첫 사용 홈 |
| `pibot-check` | 검사 통과 | 일정 결과 `violations`가 비어 있을 때 | 채팅 일정 카드 위 |
| `pibot-rain` | 비 와요 | 남은 실외 일정에 비 예보 (강수확률 기준은 미정), 또는 "비 와" | 비 예보 알림, 다시 짜기 채팅 |
| `pibot-replan` | 다시 짰어요 | `replan` 결과를 골라서 반영했을 때 | 채팅 "바꿨어요" 메시지 |
| `pibot-gap` | 시간 남았어요 | `fill_gap` 추천을 보여 줄 때 | 채팅 추천 카드 위 |
| `pibot-sunset` | 노을 보러 가요 | 일몰 전 + 맑음 + 여유 시간 있을 때 해안도로 제안 | 노을 알림, 경로 카드 |
| `pibot-tired` | 피곤해요 | "피곤해" 또는 상황 버튼 | 채팅 |
| `pibot-bye` | 여행 끝 | 여행 마지막 날이 지났을 때 | 여행 끝 화면, 지난 여행 |

여러 상태가 겹치면: 비 와요 > 다시 짰어요 > 피곤해요 > 시간 남았어요 > 노을 > 기본

## 파일

- SVG 원본과 PNG(480px, 투명 배경)가 같이 있다
- 앱에서는 이 폴더에서 `app/assets/`로 복사해서 쓴다
- 움직이는 버전: `pibot-wave-animated.svg`(깜빡 → 웃으며 손 흔들기, 스플래시용), `pibot-planning-animated.svg`(지도 점선 로딩). 브라우저에서 열면 움직인다. 앱에서는 이걸 보고 Rive나 Reanimated로 만든다
