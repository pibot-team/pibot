# 브랜드

pb 두 글자로 만든 로고. p는 아래로, b는 위로 뻗고 b 위의 점은 목적지.

## 파일

| 파일 | 쓰는 곳 |
|---|---|
| `pibot-appicon.svg` / `-1024.png` | 앱 스토어 아이콘. 모서리는 OS가 깎으니 정사각형 그대로 |
| `pibot-icon.svg` / `-512.png` | 둥근 아이콘. 웹, 발표 자료 |
| `pibot-icon-flat.svg` | 유리 효과 없는 단색 아이콘. 문서, 인쇄 |
| `pibot-symbol.svg` | 배경 없는 pb. 밝은 배경 위 |
| `pibot-symbol-white.svg` | 배경 없는 흰 pb. 어두운 배경 위 |
| `pibot-favicon.svg` / `-16, 32, 48.png` | 브라우저 탭 |

앱 아이콘은 `app/assets/`에 `pibot-appicon-1024.png`를 넣으면 된다.

## 색

| 이름 | 값 | 용도 |
|---|---|---|
| 페리윙클 | `#6F8BFF` | 메인. 단색 로고, 버튼 |
| 라이트 | `#A9BCFF` | 아이콘 배경 밝은 쪽 |
| 딥 | `#4A5BD9` | 워드마크, 강조 글자 |
| 라벤더 | `#E8E6FF` | 화면 보조 배경 |
| 점 | `#DDE3FF` | 단색 로고의 점 |

워드마크 글꼴은 Outfit Bold, 소문자 `pibot`.
