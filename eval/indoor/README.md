# 실내·실외 판단 비교

비 오는 날 일정을 바꾸려면 장소가 실내인지 알아야 하는데, 처음에는 4,509곳 모두 미확인이었다.

## 기준

비 오는 날 즐길 수 있나. 실내 = 건축물 안.

- indoor: 박물관, 카페, 식당, 매장, 공방, 사찰(법당), 시장·오일장
- outdoor: 오름, 해변, 올레길, 정원, 동굴, 유적 터, 농장·수확 체험, 수상 레저
- mixed: 건물과 바깥이 둘 다 핵심 (테마파크 등)
- unknown: 판단할 근거가 없음

## 데이터

- 분류별 무작위 120곳 (seed 20261123, 관광지 60 · 쇼핑 18 · 문화시설 14 · 레포츠 14 · 음식점 14), dev 40 / test 80
- 정답은 실제 장소 기준. LLM 초안을 사람이 한 건씩 검토해 확정 (dev 7곳, test 1곳 수정)
- 파서는 dev 만 보고 만들고 고정한 뒤 test 를 한 번 쟀다

## 실행

```bash
cd ai
python ../eval/indoor/run_eval.py --split test --method hybrid --show
```

## 결과 (test 80곳)

| 방식 | 정확도 | 95% 구간 | 실외→실내 오판 | 미확인 | LLM 호출 |
| --- | --- | --- | --- | --- | --- |
| 규칙만 | 68.8% | 58~78% | 0 | 24 | 0 |
| Claude Haiku 5.5만 | 88.8% | 80~94% | 1 | 4 | 80 |
| 규칙 + Haiku | 92.5% | 85~97% | 1 | 0 | 24 |

McNemar: 규칙+Haiku vs 규칙만 19 / 0 (p<0.001), 규칙+Haiku vs Haiku만 4 / 1 (p=0.38, 차이는 작지만 비용 1/3)

- 규칙은 확신할 때만 답하고 나머지를 미확인으로 넘겨서, 규칙+LLM이 잘 맞았다 (영업시간 파서는 규칙이 확신하며 틀려서 같은 방식이 효과 없었음)
- LLM은 실내인 곳을 mixed로 보는 경우가 많았다
- 실외→실내 오판 1곳은 바닷속 체험(실외)을 mixed로 본 경우

규칙+Haiku로 DB 4,509곳을 채웠다 (규칙 3,727 · LLM 782, 약 $0.07): 실내 3,039 · 실외 1,303 · mixed 120 · 미확인 47
